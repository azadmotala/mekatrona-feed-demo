Feed recipes

A recipe tells the converter where your number sits in the JSON a web address sends back. A GitHub Action reads each recipe's source, pulls the number out, and publishes a small file on this site that a MekaTrona Dial can read. It's a test, and everything on it is public.

Prefer to be walked through it? Try the step-by-step setup. It's a mock for now: it shows you a live preview of the dial but doesn't save anything.

The converter keeps the source's own digits. The dial rounds the number to suit its scale.

3. Set up the dial

With a target, the Dial's ring lights round it: green on the good side, then amber, then red, and out to the needle in the colour of where the reading sits. With no target the ring stays dark.

Once a reading is older than this, the dial shows STALE and how old it is. That needs a reading time, picked above.

4. Save the recipe

Save on GitHub

Save on GitHub opens GitHub with the file already filled in. You'll need a GitHub account, and if you can't write to this repo, GitHub offers to send it as a proposed change. Once the recipe is on main, the Action runs within a few minutes, and the feed shows up in the table above when GitHub Pages catches up, which can take another 10 minutes. After that it's on a 10-minute schedule, which GitHub can start late. The dial reads the file from .

The file follows the dial's format, analog-dial/feed@0: value as text, at in UTC, and optionally name, unit, rangeLo, rangeHi, setHand, good, zoneMode, zoneLow, zoneHigh and staleAfterS.
